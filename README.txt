随手存 Video · 第一版

功能
1. 收藏 Instagram / 其他视频链接，并记录标题和学习备注。
2. 导入 iPhone 本地视频，在应用内预览、导出和删除。
3. 打开你有权下载的公开视频文件直链。

重要说明
- 本应用不会下载没有官方下载权限的 Instagram Reel，也不会绕过私密权限、登录限制、DRM 或作者关闭的下载设置。
- Instagram 链接收藏只保存链接和备注，不会自动变成 MP4。
- 本地视频存储在当前浏览器 IndexedDB 中。清除 Safari 网站数据、卸载浏览器或设备清理存储可能导致数据丢失，请保留原始视频备份。
- 直链下载采用浏览器打开方式；目标网站可能限制跨站访问或要求登录。

在 iPhone 上使用
PWA 需要通过 HTTPS 网站访问才能安装到主屏幕。可将本文件夹部署到你自己的静态 HTTPS 托管服务（例如 GitHub Pages），然后：
1. 用 Safari 打开部署后的网址。
2. 点击“分享”。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开“随手存”。

本地预览
电脑可在此目录运行一个静态 HTTP 服务，例如：
python3 -m http.server 8000
然后浏览器访问 http://localhost:8000
