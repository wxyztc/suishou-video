随手存 Video · 第一版

功能
1. 收藏 YouTube / Instagram / 其他视频页面链接，并记录标题和学习备注。
2. 下载可公开访问且允许跨域读取（CORS）的直接视频文件链接，并将服务器响应的原始文件字节存入浏览器 IndexedDB；应用不会转码或压缩。
3. 导入设备中的本地视频，在应用内预览、导出和删除。

下载能力与限制
- 这里的“直接视频文件链接”指响应内容本身为 MP4 等视频文件的 URL，不是 YouTube、Instagram 等网站的分享页面。
- 纯静态网页不能通用地解析这些平台的分享页，也不能保证任意网址都能下载。浏览器安全机制、跨域（CORS）、登录要求、平台权限及 DRM 都可能阻止读取；本应用不会绕过这些限制。
- 请使用网站或作者提供的官方下载/导出功能，或使用你有权保存且可直接访问的文件链接。
- 文件按服务器实际返回内容原样保存，不会转码或压缩；“原画质”取决于来源文件。保存到 IndexedDB 会受设备空间、浏览器配额和大文件内存限制。
- 请遵守适用法律、版权要求和平台条款，并确保自己有权下载及保存视频。

本地数据
- 视频保存在当前浏览器 IndexedDB 中，不会上传到本应用服务器。清除 Safari 网站数据、卸载浏览器或设备清理存储可能导致数据丢失，请保留原始视频备份。

在 iPhone 上使用
PWA 需要通过 HTTPS 网站访问才能安装到主屏幕。可将本文件夹部署到自己的静态 HTTPS 托管服务（例如 GitHub Pages），然后：
1. 用 Safari 打开部署后的网址。
2. 点击“分享”。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开“随手存”。

本地预览
电脑可在此目录运行静态 HTTP 服务，例如：
python3 -m http.server 8000
然后浏览器访问 http://localhost:8000
